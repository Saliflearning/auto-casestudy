# Security Policy

## Supported version

Only the latest version on the `main` branch and its current production deployment are supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Security** tab and **Report a vulnerability** to send a private report to the maintainer.

Do not include live credentials, private user data, or unnecessary personal information in a report. Test only with synthetic data and accounts you control.
